{# ───────────── TopSecret ───────────── #}

Java and SQLite, team of four at UVA

TopSecret

One Java app, grown over a semester. I built four parts of it.

It started as a command line.

My entry point lists the secret files and deciphers the one you pick.

Then the files moved into SQLite.

I wrote the connection manager and the first repository.

The first account runs the place.

Everyone after is a standard user and never sees the admin menu.

Admins manage everyone but themselves.

Every promotion and demotion lands in the audit log.

Then it went to the web.

I added the login page, sessions and protected routes.
