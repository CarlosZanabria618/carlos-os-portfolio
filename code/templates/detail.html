From the code

My access-level rule in Java. An admin can promote another user but never themselves, the caller has to be an admin, and every change is written to the audit log.

public void promoteUser(String callerUsername, String targetUsername) throws SQLException {
    if (callerUsername.equals(targetUsername)) {
        throw new IllegalArgumentException("You cannot promote yourself.");
    }

    User caller = userRepository.findByUsername(callerUsername);
    if (caller == null || !caller.isAdmin()) {
        throw new IllegalArgumentException("Only admins can promote users.");
    }

    User target = userRepository.findByUsername(targetUsername);
    if (target == null) {
        throw new IllegalArgumentException("User not found: " + targetUsername);
    }

    userRepository.setAdmin(targetUsername, true);
    auditRepository.log(callerUsername, "PROMOTE_USER", targetUsername);
}

Each change lands as a row in the team's SQLite audit table, written through a prepared statement:

CREATE TABLE IF NOT EXISTS audit_log (
    id        INTEGER PRIMARY KEY AUTOINCREMENT,
    username  TEXT,
    action    TEXT NOT NULL,
    target    TEXT,
    timestamp TEXT
);

INSERT INTO audit_log(username, action, target, timestamp)
VALUES (?, ?, ?, datetime('now'));
